# Content Calendar

Plan and manage content publishing schedules with structured workflows, content pillar frameworks, and editorial planning templates.

## Purpose

Create a systematic content publishing plan that maintains consistency, aligns with business goals, and distributes content effectively across channels. Covers calendar planning, content pillars, workflow stages, frequency guidelines, and seasonal planning.

## Workflow

### Content Production Stages

```
CONTENT WORKFLOW STAGES

STAGE 1: IDEATION (Week 1)
- [ ] Review content pillars and gaps
- [ ] Research trending topics and keywords
- [ ] Collect team input and customer questions
- [ ] Prioritize ideas by impact and effort
- [ ] Assign topics to writers
Status: Backlog → Approved

STAGE 2: CREATION (Week 2-3)
- [ ] Writer creates outline
- [ ] Outline approved by editor
- [ ] First draft written
- [ ] Internal links and CTAs added
- [ ] Images and media sourced
Status: In Progress → Draft Complete

STAGE 3: REVIEW (Week 3)
- [ ] Editorial review (grammar, tone, clarity)
- [ ] SEO review (keywords, meta, headings)
- [ ] Subject matter expert review (accuracy)
- [ ] Legal/compliance review (if needed)
- [ ] Revisions completed
Status: In Review → Approved

STAGE 4: PUBLISH (Week 4)
- [ ] Format in CMS
- [ ] Add featured image, alt text, categories
- [ ] Set meta title, description, URL slug
- [ ] Schedule publish date and time
- [ ] Set up social media distribution
Status: Scheduled → Published

STAGE 5: PROMOTE (Week 4+)
- [ ] Share on social channels
- [ ] Include in newsletter
- [ ] Internal distribution (sales, support)
- [ ] Outreach for backlinks
- [ ] Monitor performance (traffic, engagement)
Status: Promoting → Monitoring

STAGE 6: OPTIMIZE (Ongoing)
- [ ] Review performance at 30, 60, 90 days
- [ ] Update content if underperforming
- [ ] Refresh outdated information
- [ ] Add new internal links from newer content
Status: Active → Refreshed
```

## Best Practices

1. **Plan quarterly, execute weekly** - Quarterly strategy, monthly themes, weekly execution
2. **Balance pillars** - No single pillar should exceed 40% of total content
3. **Build a backlog** - Maintain 2-3 months of approved topics ready to assign
4. **Batch production** - Group similar content types for efficiency
5. **Repurpose everything** - One hero piece should become 5-10 derivative pieces
6. **Leave room for reactive content** - Keep 20% capacity for trending topics
7. **Track the pipeline** - Visibility into what is in progress prevents last-minute scrambles
8. **Measure and prune** - If a content type consistently underperforms, stop producing it
9. **Align with sales** - Content should support active sales campaigns and objections
10. **Review monthly** - Adjust next month's plan based on this month's performance
