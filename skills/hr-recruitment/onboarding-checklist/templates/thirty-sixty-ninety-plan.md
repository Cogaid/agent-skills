## Pre-Boarding (Offer Acceptance to Day 1)

### HR / People Ops

- [ ] Send welcome email with Day 1 logistics
- [ ] Ship/prepare welcome kit
- [ ] Send employment paperwork for pre-completion
- [ ] Set up payroll and benefits enrollment
- [ ] Create employee record in HRIS
- [ ] Schedule orientation sessions
- [ ] Notify building security / reception

### Hiring Manager

- [ ] Send personal welcome message
- [ ] Assign onboarding buddy
- [ ] Draft this 30-60-90 day plan
- [ ] Schedule recurring weekly 1:1s
- [ ] Brief team on new hire start date and background
- [ ] Identify first project / quick win assignment
- [ ] Schedule key stakeholder meetings for Weeks 1-2

### IT / Operations

- [ ] Order and configure laptop/equipment
- [ ] Create email and corporate accounts
- [ ] Set up tool access (see checklist below)
- [ ] Prepare VPN and security credentials
- [ ] Ship equipment (remote: arrive 2+ days before start)

## FIRST 30 DAYS: LEARN

**Theme:** Absorb context, build relationships, deliver a quick win
**Manager check-in frequency:** Weekly (30-45 min)
**Buddy check-in frequency:** Daily (Week 1), then twice weekly

### Week 1 Checklist

- [ ] Complete all HR paperwork and compliance training
- [ ] Access all required tools and systems
- [ ] Meet all immediate team members
- [ ] Establish check-in rhythm with buddy
- [ ] Review team goals, OKRs, and current projects
- [ ] Attend first team meeting
- [ ] Complete mandatory training (security, compliance)
- [ ] Understand team communication norms
- [ ] Read key documentation
- [ ] Have first 1:1 with manager to align on expectations

### Weeks 2-4 Checklist

- [ ] Complete all onboarding training modules
- [ ] Deliver first quick win or small deliverable
- [ ] Attend cross-functional meetings
- [ ] Understand team workflow and processes
- [ ] Build relationships with 5+ colleagues outside immediate team
- [ ] Complete Week 1 onboarding feedback survey
- [ ] Receive first informal feedback from manager
- [ ] Identify one area of confusion and raise it
- [ ] Understand performance measurement approach

### 30-Day Check-In Questions (Manager)

1. How is the new hire progressing against goals?
2. Are there any tool access or resource gaps?
3. How is the relationship with the buddy working?
4. Any concerns about fit, performance, or engagement?
5. What support does the new hire need for the next 30 days?
