# Reminder Templates

Use these templates when creating reminders. Include context so the reminder is actionable when it fires.

## 1. Simple Reminder

```
REMINDER
--------
What: [Specific action to take]
When: [Date/Time]
Why: [Context - what prompted this]
Priority: [Urgent / High / Normal / Low]

Details:
[Any additional info needed when this fires]
```

## 2. Follow-up Reminder

```
FOLLOW-UP REMINDER
------------------
Original action: [What you did - email sent, request made, etc.]
Date sent/done: [Date of original action]
Waiting for: [Person/Response expected]
Days elapsed: [X] days

Context:
[Brief recap of what was discussed/requested]

Suggested follow-up action:
[Template message or next step]

Escalation: [Next step if still no response]
```

## 3. Recurring Reminder

```
RECURRING REMINDER
------------------
What: [Task to repeat]
Frequency: [Daily / Weekly / Monthly / Custom]
Next occurrence: [Date]
Last completed: [Date]

Checklist:
[ ] [Step 1]
[ ] [Step 2]
[ ] [Step 3]

Notes:
[Any variations or updates to the routine]
```

## 4. Deadline Reminder

```
DEADLINE APPROACHING
--------------------
Task: [What is due]
Deadline: [Date/Time]
Time remaining: [X days/hours]
Priority: [Based on remaining time]

Status: [Not started / In progress / Almost done]

Remaining work:
1. [Step 1] - Est: [time]
2. [Step 2] - Est: [time]
3. [Step 3] - Est: [time]

Total estimated time needed: [X hours]
Available time before deadline: [Y hours]
Buffer: [Y - X hours]
```

## 5. Meeting Prep Reminder

```
MEETING PREP
------------
Meeting: [Meeting name]
When: [Date/Time] (in [X hours/days])
With: [Attendees]
Location: [Where/Link]

Prep needed:
[ ] [Review document X]
[ ] [Prepare talking points for Y]
[ ] [Send agenda to attendees]
[ ] [Test screen share / links]

Key topics to raise:
- [Topic 1]
- [Topic 2]

Documents to bring:
- [Doc 1]
- [Doc 2]
```

## 6. Bill/Payment Reminder

```
PAYMENT DUE
-----------
What: [Bill/subscription name]
Amount: [$ amount]
Due date: [Date]
Days until due: [X]

Payment method: [Card/Account]
Auto-pay: [Yes/No]

Action needed: [Pay manually / Verify auto-pay / Update card]
```

## 7. Escalation Reminder

```
ESCALATION NEEDED
-----------------
Original request: [What was asked]
Sent to: [Person]
Date sent: [Date]
Follow-ups sent: [Count]
Days waiting: [X]

Previous attempts:
1. [Date] - [Method] - [Result]
2. [Date] - [Method] - [Result]

Escalation action:
[Next step - CC manager, try different channel, close out]
```

## 8. Health/Wellness Reminder

```
HEALTH REMINDER
---------------
What: [Medication / Appointment / Exercise / Break]
When: [Time]
Frequency: [Daily / As scheduled]

Details:
[Dosage, location, routine specifics]

Skip conditions:
[When it is OK to skip - e.g., "skip if already exercised today"]
```

## Follow-up Email Templates

### Gentle Follow-up (Day 3)

```
Subject: Following up - [Topic]

Hi [Name],

I wanted to follow up on [topic] from [date/context].

[Brief reminder of what was discussed/sent]

Do you have any questions, or would you like to move forward?

Happy to jump on a quick call if easier.

Best,
[Your name]
```

### Direct Follow-up (Day 7)

```
Subject: Re: [Original Subject]

Hi [Name],

Just checking in again on [topic]. I know things get busy.

[One-sentence reminder of what you need]

Let me know if you need anything from my end, or if priorities have shifted.

Thanks,
[Your name]
```

### Final Follow-up (Day 14)

```
Subject: Should I close this out? - [Topic]

Hi [Name],

I've reached out a few times about [topic] but haven't heard back.
I'll assume the timing isn't right and close this out for now.

If things change, just let me know - happy to reconnect.

Best,
[Your name]
```
