# Meeting Summary Templates

Select the appropriate template based on meeting type. Use `meeting_summarizer.py --type <type>` to generate.

## 1. Standard Meeting Summary

Use for: Regular team meetings, project check-ins, planning sessions.

```
# Meeting Summary: [Meeting Name]

Date: [Date]
Duration: [X] minutes
Attendees: [Names]
Facilitator: [Name]
Note-taker: [Name]

## Key Decisions
1. [Decision 1]
2. [Decision 2]
3. [Decision 3]

## Action Items

| Action | Owner | Due Date |
|--------|-------|----------|
| [Task 1] | [Name] | [Date] |
| [Task 2] | [Name] | [Date] |
| [Task 3] | [Name] | [Date] |

## Discussion Summary
[2-3 paragraph summary of main topics discussed]

## Open Questions
- [Question 1]
- [Question 2]

## Next Steps
- Next meeting: [Date/Time]
- [Other follow-ups]
```

## 2. Executive Brief

Use for: Leadership updates, skip-level reporting, busy stakeholders.

```
# [Meeting Name] - Executive Brief
[Date] | [Duration]

DECISIONS:
- [Key decision 1]
- [Key decision 2]

ACTIONS (requires your attention):
- [Action needing exec input] - Due: [Date]

KEY INSIGHT:
[One-sentence most important takeaway]

RISK/BLOCKER:
[Any escalation needed, or "None"]

NEXT: [Next meeting/checkpoint]
```

## 3. Action-Focused Summary

Use for: Sprint planning, task-heavy meetings, project kickoffs.

```
# Action Items from [Meeting Name]
[Date]

## Immediate (This Week)
- [ ] [Action] - @[Owner] - Due: [Date]
- [ ] [Action] - @[Owner] - Due: [Date]

## This Sprint/Month
- [ ] [Action] - @[Owner] - Due: [Date]
- [ ] [Action] - @[Owner] - Due: [Date]

## Backlog/Future
- [ ] [Action] - @[Owner] - No date set

## Decisions Made
- [Decision 1]
- [Decision 2]

## Blocked/Needs Input
- [Blocked item] - Waiting on: [Person/Thing]
```

## 4. One-on-One Meeting

Use for: Manager/report 1:1s, mentor meetings, skip-levels.

```
# 1:1: [Person A] <-> [Person B]
[Date]

## Check-in
- How they are doing: [Brief]
- Energy level: [High/Medium/Low]

## Wins Since Last Time
- [Win 1]
- [Win 2]

## Challenges/Blockers
- [Challenge 1]
  - Support needed: [What]

## Discussion Points
- [Topic 1]: [Outcome]
- [Topic 2]: [Outcome]

## Actions
- [Name]: [Action] by [Date]
- [Name]: [Action] by [Date]

## Career/Development
- [Notes on growth, feedback, goals]

## Next 1:1: [Date]
```

## 5. Sprint/Project Meeting

Use for: Sprint reviews, project status meetings, iteration planning.

```
# [Sprint/Project] Meeting - [Date]

## Status
- Overall: [On Track / At Risk / Blocked]
- Completion: [X]%

## Completed Since Last Meeting
- [Item 1]
- [Item 2]

## In Progress

| Item | Owner | Status | Blocker |
|------|-------|--------|---------|
| [Task] | [Name] | [X]% | [If any] |

## Blockers/Risks
- [Blocker 1]: [Mitigation]

## Decisions Needed
- [Decision 1] - Decided: [Outcome]

## Next Sprint/Phase
- Focus: [Main focus]
- Key deliverables: [List]

## Actions
- [Action] - @[Owner] - Due: [Date]
```

## 6. Client/External Meeting

Use for: Client calls, vendor meetings, partnership discussions.

```
# Client Meeting: [Client Name]
[Date] | [Location/Call]

## Attendees
Internal: [Names]
Client: [Names + Titles]

## Meeting Purpose
[Why this meeting was held]

## Client Updates
- [Update 1]
- [Update 2]

## Our Updates
- [Update 1]
- [Update 2]

## Agreements/Decisions
- [Agreement 1]
- [Agreement 2]

## Action Items

| Action | Owner | Due |
|--------|-------|-----|
| [Client action] | [Client name] | [Date] |
| [Our action] | [Our name] | [Date] |

## Follow-up
- Next meeting: [Date]
- Deliverables due: [What by When]

## Internal Notes (do not share with client)
[Observations about relationship, opportunities, concerns]
```

## 7. All-Hands / Town Hall

Use for: Company-wide meetings, department updates, announcements.

```
# All-Hands Summary - [Date]

## Key Announcements
1. [Announcement 1]
2. [Announcement 2]

## Company Metrics
- [Metric 1]: [Value]
- [Metric 2]: [Value]

## Strategic Updates
- [Update on direction/priorities]

## Q&A Highlights
- Q: [Question] - A: [Answer]
- Q: [Question] - A: [Answer]

## Action Items for Our Team
- [Action relevant to us]

## Next All-Hands: [Date]
```
