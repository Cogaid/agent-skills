# Quick Email Response Templates

## Usage

Copy and customize these templates for common email responses. Replace placeholders in `{{ }}` with actual values.

---

## Acknowledge and Defer

```
Subject: Re: {{original_subject}}

Thanks for sending this, {{name}}. I'll review and get back to you by {{date}}.
Let me know if anything is urgent before then.

Best,
{{your_name}}
```

## Delegate

```
Subject: Re: {{original_subject}}

Thanks, {{sender_name}}. I'm looping in {{delegate_name}} who can help with this
directly. {{delegate_name}}, could you take a look?

Best,
{{your_name}}
```

## Request More Information

```
Subject: Re: {{original_subject}}

Thanks for reaching out. Before I can help, could you clarify:

1. {{specific_question_1}}
2. {{specific_question_2}}

That will help me give you a more useful response.

Best,
{{your_name}}
```

## Decline Meeting

```
Subject: Re: {{meeting_subject}}

Thanks for the invite. I don't think I'll be able to add value to this meeting,
but I'm happy to review any notes or decisions that come out of it.

Feel free to send a summary afterward.

Best,
{{your_name}}
```

## Close Thread

```
Subject: Re: {{original_subject}}

This looks resolved -- closing the loop. Let me know if anything else comes up.

Best,
{{your_name}}
```

## Approval / Sign-off

```
Subject: Re: {{original_subject}}

Looks good to me -- approved.

{{any_conditions_or_notes}}

Best,
{{your_name}}
```

## Scheduling a Meeting

```
Subject: Re: {{original_subject}}

Good idea to discuss this live. Here are some times that work for me:

- {{option_1}}
- {{option_2}}
- {{option_3}}

Let me know what works, or feel free to grab a slot on my calendar:
{{calendar_link}}

Best,
{{your_name}}
```

## Saying No Politely

```
Subject: Re: {{original_subject}}

Thanks for thinking of me. Unfortunately, I can't take this on right now
due to {{brief_reason}}.

{{alternative_suggestion_or_referral}}

Best,
{{your_name}}
```

## Follow-up After No Response

```
Subject: Following up - {{original_subject}}

Hi {{name}},

I wanted to follow up on my email from {{date}}. I understand things get busy.

{{brief_recap_of_original_ask}}

Let me know if you have any questions or if priorities have changed.

Best,
{{your_name}}
```

## Final Follow-up

```
Subject: Should I close this out? - {{original_subject}}

Hi {{name}},

I've reached out a few times about {{topic}} but haven't heard back.
I'll assume the timing isn't right and close this out for now.

If things change, just let me know -- happy to reconnect.

Best,
{{your_name}}
```
